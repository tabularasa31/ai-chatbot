## 2026-09-29 — Widget identity verification

You can now prove that a `user_id` passed to the widget really belongs to the visitor.

**What's new:** a tenant owner can generate a signing key in **Dashboard → Widget settings → Widget identity verification**. Your server computes a `user_hash` from the key and the visitor's `user_id`, and passes it alongside `user_id` in `userHints`.

**What it means:** conversations now continue across devices, and sessions are grouped in the Inbox, only for verified visitors. A `user_id` without a valid `user_hash` personalizes the conversation and keeps it on the same browser.

**What to do:** if you pass `user_id` and want conversations to follow visitors across devices, set up verification.

See [Embedding the Widget → Identity verification](/docs/embedding-the-widget#identity-verification) for the full setup guide.
